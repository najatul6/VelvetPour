# 📖 About

VelvetPour is a full-stack MERN application built for modern coffee shops and cafés. The platform enables users to browse handcrafted coffee collections, discover featured drinks, explore café services, and enjoy a fast, secure, and responsive experience across all devices.

- ☕ Explore Premium Coffee Menu
- 🥐 Browse Featured Drinks & Snacks
- 🛒 Easy Online Ordering Experience

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/najatul6/VelvetPour.git
```

Move into the project

```bash
cd VelvetPour
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
