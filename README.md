### 📖 Description
**VelvetPour** is a sophisticated web application built for a premium beverage brand. It focuses on a "velvet-smooth" user experience, utilizing the latest **React 19** features and the lightning-fast **Vite 7** build tool. The interface is crafted using **Tailwind CSS v4** and **DaisyUI** for a clean, modern aesthetic.

### ✨ Key Features
- ⚡ **Ultra-Fast Performance:** Built with Vite 7 for near-instant load times.
- 🎨 **Modern UI:** Styled with Tailwind 4 and DaisyUI components.
- 📱 **Fully Responsive:** Optimized for mobile, tablet, and desktop viewing.
- 🧭 **Seamless Navigation:** Integrated with React Router 7.
- ✨ **Smooth Animations:** Enhanced with `animate.css` for a premium feel.

### 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
```bash 
git clone https://github.com/najatul6/VelvetPour.git
cd VelvetPour

```

2. **Install dependencies:**
```bash
npm install

```


3. **Start the development server:**
```bash
npm run dev

```


4. **Build for production:**
```bash
npm run build

```
